# Perfume Shopping Mobile App – HCI UX Project

## 📱 Project Overview

This project is a 24-screen mobile application prototype designed for a perfume shopping experience as part of a Human-Computer Interaction (HCI) academic project.

The project focuses on applying HCI and UX/UI design principles to create a simple, user-friendly and interactive shopping experience.

## 🎯 Project Objective

The main objective of this project was to design a mobile application that provides users with an easy and intuitive way to discover and purchase perfumes.

## 🔎 User Research

Before designing the application, a small user survey was conducted using Google Forms to understand customer preferences and expectations related to perfume shopping.

### Research Details

- Number of respondents: 23
- Research tool: Google Forms
- Target users: Potential perfume shopping customers
- Research approach: Online survey

The research insights were considered during the UX/UI design process.

## 🎨 UX/UI Design Process

The project followed a basic user-centred design process:

1. User Research
2. Identifying User Needs
3. Planning the User Flow
4. Wireframing
5. UI Design
6. Interactive Prototyping

## ✨ Main Features

The prototype includes screens and interactions for:

- Home page
- Product discovery
- Product categories
- Search
- Product details
- Shopping cart
- Checkout
- Order flow
- User navigation
